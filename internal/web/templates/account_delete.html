Account

Delete your account

Deletion is immediate. Your account, shelf and play log are removed the moment you confirm; nothing is held for a waiting period.

Delete it yourself

{{if .User}}

You are signed in as {{.User.Email}}. Open Settings → Account, type DELETE in the confirmation box and submit the form.

{{else}}

Sign in, open Settings → Account, type DELETE in the confirmation box and submit the form. Sign in if you have not already.

{{end}}

In the Android app the same action lives under Settings → Account → Delete account. It calls DELETE /api/v1/me with the same typed confirmation, then clears the token from the device.

If you cannot sign in

{{if .Legal.ContactEmail}}

Write to {{.Legal.ContactEmail}} from the address on the account and ask for it to be deleted. Requests are handled within one month, usually much sooner.

{{else}}

Ask the operator or administrator of this instance to delete the account for you. There is no self-service route that works without signing in.

{{end}}

What is removed

  • Your email address, display name, avatar URL, role metadata and last sign-in time.
  • Your BoardGameGeek username, sync settings, theme and timezone.
  • Every shelf entry, including private notes, location, condition and price paid.
  • Every play you own, including its location, notes and the player-name rows attached to it.
  • Every uploaded setup-guide photo and its stored file in the setup media directory.
  • Every way into the account: browser sessions and personal API tokens.
  • Sync history associated with the account.

Database rows are deleted in one transaction. If any database step fails, nothing is deleted. Stored setup photos are removed after that transaction commits.

{{if .Legal.Demo}}If the account is the public demo account, it is not gone for good: the server recreates it from sample data on the next restart. Its contents are sample data, not personal data. Deleting the demo account while the instance is running leaves it unavailable until that restart.{{end}}

What is not removed

  • Your Authelia / OpenID Connect account. The login provider is a separate identity account. Deleting {{.AppName}} does not delete it, and signing in with it again may create a new empty shelf account. Delete the provider account separately if you want that identity removed.
  • Backups taken before deletion. They may still contain the old data until they rotate out, and are not used to restore an individual account.
  • Server logs and traces already written, which expire on the operator's retention schedule.

The last remaining admin account cannot be deleted until another admin is promoted, because that would leave the instance unadministrable.

If your name appears in someone else's play log

Board game players are stored as free-text names on another person's play. If you are not a user and want your name removed, use the contact address above and tell us the name and, if you know it, the account or approximate date. The operator can remove or anonymise all matching player-name rows. Signed-in users can also remove a name from their own plays under Settings → Privacy controls; that tool never exposes another person's play log.

The full detail is in the privacy policy.
