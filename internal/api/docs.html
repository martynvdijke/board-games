The Shelf · API v1

A small, predictable API.

Everything the web app does with games, plays, stats, and sync is available to scripts, the Android companion, and TRMNL. Authentication is bearer-only.

Create a token in Settings → API tokens. Scopes are read, write (implies read), and trmnl. Treat tokens like passwords.
OpenAPI 3.1 specificationBack to the shelf

Authentication

curl -H "Authorization: Bearer bg_your_token" \
  http://localhost:6290/api/v1/games

Unauthorized requests return 401 with WWW-Authenticate: Bearer. Missing scopes return 403. Rate limit: 120 requests per minute per user.

Errors

{
  "error": {
    "code": "invalid_request",
    "message": "played_at must be YYYY-MM-DD",
    "fields": { "played_at": "invalid date" }
  }
}

Quick start

# Who am I?
curl -sH "Authorization: Bearer $SHELF_TOKEN" \
  "$SHELF_URL/api/v1/me"

# Games that have never been played
curl -sH "Authorization: Bearer $SHELF_TOKEN" \
  "$SHELF_URL/api/v1/games?status=unplayed&per_page=50"

# Log a play
curl -s -X POST "$SHELF_URL/api/v1/plays" \
  -H "Authorization: Bearer $SHELF_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"game_id":42,"played_at":"2026-10-20","location":"Home","players":[{"name":"Sam","is_winner":true}]}'
